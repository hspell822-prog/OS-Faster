# FastOS ⚡

Ek browser-based operating system jo HTML, CSS aur JavaScript mein bana hai.

## Features
- 🖥️ Desktop with icons
- 🪟 Draggable, resizable windows
- 🧮 Calculator
- 📝 Notes (localStorage)
- 💻 Terminal (commands)
- 🖼️ Custom wallpaper
- 🎬 Boot animation
- 🖱️ Right-click context menu
