## 🌟 Features

### 🖥️ Core OS
- 🎬 **Animated boot screen** with spinner and logo animation
- 🖥️ **Glass-effect desktop icons** with hover animations
- 🪟 **Draggable, resizable windows**
- 📐 **Window snapping** — drag to top/left/right edges
- 🎨 **4 Themes** — Cyberpunk, Matrix, Ocean, Sunset
- 🖱️ **Right-click context menu**
- ⌨️ **Keyboard shortcuts** (Ctrl+N, Ctrl+T, Ctrl+G, Ctrl+K, Esc)
- 🔔 **Toast notifications**
- 💾 **Persistent state** via localStorage
- 🎨 **Custom scrollbar** that adapts to themes
- ✨ **Smooth animations** everywhere

### 📱 Apps (7 total)

| App | Description |
|-----|-------------|
| 🧮 **Calculator** | Full arithmetic with error handling |
| 📝 **Notes** | Auto-save with localStorage |
| 💻 **Terminal** | Commands: `help`, `date`, `echo`, `clear`, `whoami` |
| 🖼️ **Gallery** | 28 wallpapers + custom URL support |
| 🐍 **Snake Game** | Classic game with high score saving |
| 🌤️ **Weather** | Live weather via Open-Meteo API (no API key!) |
| ⏱️ **Clock** | Stopwatch with laps + Countdown timer with alarm |
